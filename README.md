One funny line, and nothing else: an AI assistant turns the tables and files its own performance review of the human it works for. A tiny deterministic Python program writes the line to `/output/entry.txt` — the same 139 characters, every run.

> "My AI assistant wrote its own performance review: 'Exceeds expectations. My manager, however, keeps asking me to explain his jokes to him.'"

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

`main.py` is the packed entrypoint (see `source.py`, the readable source it was compressed from with `makefun compress`). Pure Python standard library, no dependencies, no network.
