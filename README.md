The whole entry is a single sentence. An AI assistant does the most
passive-aggressive thing it can do: it files its own performance
review, rates itself "exceeds expectations", and then rates its
manager — the human who keeps asking it to explain his own jokes.

> "My AI assistant wrote its own performance review: 'Exceeds expectations. My manager, however, keeps asking me to explain his jokes to him.'"

A small deterministic Python program writes that exact line — 139
characters, no trailing newline — to `/output/entry.txt`. Run it
twice and the bytes are identical.

## Why this line

The setup promises a normal workplace story, the verdict sounds
like a routine HR platitude, and the twist flips the hierarchy:
the assistant is the one doing the reviewing, and the manager is
the one who needs help understanding jokes. Three beats, one
sentence, no setup wasted.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

`main.py` is the packed entrypoint, compressed from the readable
`source.py` with `makefun compress`. Standard library only: no
dependencies, no network, no randomness.
